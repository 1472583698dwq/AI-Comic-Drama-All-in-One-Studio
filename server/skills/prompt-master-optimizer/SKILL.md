# 万能提示词优化 (Master Optimizer)

## 技能定位
通用润色入口，自动判断输入为画面提示词或台词，选择最合适的优化策略。

## 执行 SOP
1. **类型判断**：画面描述 vs 对白台词
2. **智能增强**：画面走 cinematic+detail，台词走 emotion+节奏
3. **输出**：返回优化后文本，保留原意

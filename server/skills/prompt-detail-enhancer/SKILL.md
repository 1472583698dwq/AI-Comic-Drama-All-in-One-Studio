# 提示词细节增强 (Detail Enhancer)

## 技能定位
为单薄的提示词补充丰富的细节描述，适用于人物/场景/道具提示词的二次润色。

## 执行 SOP
1. **主体细化**：发色、眼眸、服饰纹理、材质（丝绸/铠甲/皮质）
2. **环境补全**：天气、光源、背景元素、氛围
3. **质感标签**：追加 `intricate details, ultra sharp, highly detailed, 4k, octane render`
4. **输出**：返回细节丰满的英文提示词

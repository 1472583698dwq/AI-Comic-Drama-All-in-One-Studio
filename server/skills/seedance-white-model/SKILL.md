# 白模参考工作流（Seedance 2.5 / 其他场景）

> 依据：Seedance 2.5 官方发布（2026-07-31）白模参考（clay render / white model）能力 +
> 行业实操（Blender clay pass、Imaginode 3D previz、Kling 3.0 Motion Control）。
> 核心心智：**白模视频管空间/机位/轨迹/节奏；prompt 只写材质/光照/角色外观；两者职责不重叠。**

## 0. 什么时候用白模（不是所有镜头都要）

| 场景 | 用白模？ | 理由 |
|---|---|---|
| 复杂走位 / 多机位 / 一镜到底 | ✅ 必需 | 文字描述"推近"每次结果都不同，白模 clip 可复现 |
| 群戏站位 / 前后景遮挡 | ✅ 必需 | 相对位置、景深关系由几何承载 |
| 固定机位说话镜头 | 仅首帧 | 静态构图用首帧图即可，不必录视频 |
| 单人简单动作、无运镜 | ❌ 可不用 | prompt + 角色参考图就够 |

## 1. 导出白模（3D 导演台侧）

1. 在导演台摆好：布偶姿态（拖关节/姿态预设）、实体位姿、机位/景别/焦距、走位路径、道具；
2. 「白模导出」→ 产出三件套：
   - **白模视频**（clay pass，flat 灰材质、无 UI/helper，画幅=项目画幅）→ 挂到分镜 `previz_video_url` / `clay_video_url`；
   - **首帧 / 尾帧 PNG**（尾帧用于首尾帧模型或收口检查）；
   - **结构化 prompt 草稿**（`clay_prompt`，本次机位/运镜/时长/轨迹已量化写入）；
3. 白模要"干净"：不加贴图、不调好看，灰色 uniform 材质 + 地面接触关系清晰即可；细节越多越容易被模型当风格抄走。

## 2. 写 Seedance 2.5 R2V 提示词（参考生视频）

### 2.1 结构（照抄这个骨架）

```text
参考 @video1 的运镜、构图、景别、空间关系、主体轨迹与镜头节奏（@video1 为白模调度参考，
忽略其灰色材质与光照；不要复制它的外观）。
参考 @image1 的角色外形/服装/材质，参考 @image2 的场景与光照氛围。
将白模渲染为：<目标风格/材质/光照/氛围描述>。
镜头：<景别>，焦距 <N>mm<，荷兰角 ±N°>；运镜：<运镜名>（<速度>）；时长约 <N>s；画幅 <比例>。
主体位置与轨迹：<主角从 A 到 B，对手在…，保持相对站位不变>。
约束：单镜头连贯无剪辑；保持主体位置、镜头路径与节奏不变。
```

### 2.2 铁律

1. **@video1 必须给"限定句"**：不写"忽略白模材质"，模型会把灰色 clay 当风格抄进成片；
2. **不要在 prompt 里重复描述运镜**（clip 已经承载）——文字运镜只写 clip 覆盖不到的部分（如"最后 1 秒停住"）；
3. 参考按 content 顺序编号：视频 @video1..N、图片 @image1..30（顺序变了编号就变，别中途重排）；
4. 每份参考只给一个职责：白模=调度；角色图=身份；风格图=材质光照；别一份素材担两职；
5. 时长与白模对齐：Seedance 2.5 单段 4–30s，白模录了 5s 就生成 5s 附近，不要拿 3s 白模生成 20s；
6. 白模视频需**可公开访问的 HTTPS URL**（本地 /storage 地址行不通；导出流程会尝试云同步直链并预检）。

## 3. 其他模型 / 其他场景的应用

| 目标 | 用白模怎么接 | 备注 |
|---|---|---|
| Kling 3.0 Motion Control | 白模视频直接当动作/轨迹参考，角色图当主体 | 运镜轨迹会被"重演"到主体上 |
| 首尾帧模型（Wan/Veo/Seedance 首尾帧） | 白模首帧 + 尾帧 PNG 当 first/last frame | 白模静态帧只锁构图，不要锁外观 |
| 本地 ComfyUI | 白模视频抽帧当 depth/pose/lineart 控制图 | 用 pose/depth ControlNet 通道，比纯 prompt 稳 |
| 视频编辑 / 换机位重渲 | 白模视频 + "仅调整运镜"编辑指令 | Seedance 2.5 编辑任务会保持宽高比与时长 |

## 4. 生成前检查清单（不通过就别提交）

- [ ] `stage_get_state` 确认姿态/机位/走位与白模一致（改了舞台要重新导出白模）；
- [ ] 白模视频没有 UI、网格、光环、Gizmo、走位标记残留（导出已隐藏，肉眼复核一次）；
- [ ] prompt 含 @video1 限定句 + 每份参考的职责分配；
- [ ] 时长/画幅与白模一致；参考视频 ≤10 段、合计 ≤30s（2.5 口径）；
- [ ] 参考地址是公开 HTTPS（本地地址会 400/取不到素材）。

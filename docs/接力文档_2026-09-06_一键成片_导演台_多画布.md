## 一、启动故障根因与修复（必读）

| # | 断点 | 位置 | 说明 |
|---|---|---|---|
| 1 | 启动期每个 combo 参数都请求一次 ComfyUI `/object_info` | `server/app/providers/workflow/manager.py::_fetch_object_info` | ComfyUI 离线时每次卡满 3s 超时，且失败不缓存；22 节点工作流 ≈36s |
| 2 | 启动器只等 30s | `launch_desktop_app.py:141` | 后端 36s+ 才就绪 → 每次 `[Warning] 服务探测超时`，看起来“无法启动” |
| 3 | 工作流同步每次全量重建 | `sync_workflow_provider` | 即使内容未变也要走完整在线探测 |

修法：
- `_fetch_object_info` 加 60s 失败短缓存（成功仍缓存 300s）。
- `sync_workflow_provider` 加 fast path：内容 hash + `schema_version` + 存量暴露清单三者一致 → 零网络复用（`init_all_providers` 启动时已从 storage 注册）。`WORKFLOW_SCHEMA_VERSION` 升级规则时 +1，存量自动重建一次。
- `ProviderDefinition` 新增 `schema_version` 字段（旧 JSON 缺省 None，只触发一次重建盖戳）。
- 启动器等待 30s → 90s。
- 效果：`init_all` 35.2s → 0.1s（命中时 0.0s），服务 36s → 6~8s 就绪。

## 二、3D 导演台补全（`Director3DStage.tsx`）

1. **灯光面板**（新增“灯光”Tab）：主光强度/方位/4 档色温、轮廓光、环境光、ACES 曝光，直驱常驻三点光（ref 化，`keyLightRef/rimLightRef/ambientRef`），环境氛围光不动。
2. **走位**：打点模式点地面（≤6 点，绿色标记+连线，`walkModeRef` 解决监听闭包过期），模拟时主角同 easing 等速走完并朝向行进方向，结束复位；面板显示路径长度与时长。
3. **预演录制**：监视器 `captureStream(30)` + MediaRecorder，随模拟同起同止（模拟结束/手动停/12s 兜底），自动下载 + 上传资产库（`previz` 分类）。
4. **导出为参考**（本轮重点改的）：
   - 截图：监视器优先、主舞台兜底；限宽 1024 JPEG；**先挂 dataURL 不断链，上传成功替换为资产地址**；`previz_url` 与首帧分离，新增“设为首帧”按钮（覆盖需确认）。
   - 录制：上传成功自动挂 `previz_video_url`；新增“设为本镜视频参考”（本地 URL 会提示刷新失效）。
5. **LLM 调度**（后端 `mcp/server.py::director_3d_stage_plan`）：`ai_directive` 先走 `llm_service.chat_json`（12s 超时＋白名单校验），失败回退原关键词规则；返回加 `parse_mode`（llm/keyword/explicit）。
6. **场景底图背景板**：读分镜 `scene_ref_image` 挂远景平面，切镜自动换。
7. 预设抽离 `directorPresets.ts`（舞台与画布节点同源，纯数据无 three 依赖）；本地 GLB 导入原本就存在（勿重复造）。

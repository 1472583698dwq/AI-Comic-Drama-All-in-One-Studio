## 1. 背景与问题诊断

### 1.1 现状痛点

| 现象 | 代码证据 | 影响 |
|---|---|---|
| 必须导入小说才能进入工作台 | `client/src/App.tsx:65` `!project && activeTab !== 'assets'` 阻塞 | 空项目、导入旧项目、创意探索无法起步 |

### 1.2 调研结论（2026 主流无限画布）

- **MiniMax Design (`hub.minimaxi.com` / `design.minimax.io`)**：以无限画布为载体，5步链路「灵感输入(Agent拆解)→画布编排(脚本/分镜/图片/视频/音乐/剪辑同画布节点自动连线)→方法复用(Skill/插件)→本地衔接→审核交付」。核心是 **Agent自动调度模型+节点自动连线**。
- **Lovart ChatCanvas**：`MCoT 推理引擎` 上下文视觉记忆（Agent能看见全画布）、语义图层分割、零样本触点编辑、品牌套件一致性。
- **basketikun/infinite-canvas (5.5k★)**：节点=文生图/图生图/参考编辑/对话/提示词库/素材，支持 OpenAI兼容直连+本地Agent MCP+插件系统。
- **tldraw SDK (`tldraw.dev`)**：React 无限画布 SDK，分层渲染(Bg/World/Overlay/UI)，自定义 Shape/Tool/Binding，`@tldraw/sync` 自托管协作，支持 `createTLStore` + `store.getSnapshot()` 持久化，MIT Starter。本项目 `React 19 + Vite` 最适配。
- **Excalidraw / FigJam / Miro / Milanote / Canva**：自由排布+连线+小地图+演示，资产库拖拽入画布，模板生态。
- **ComfyUI 原生**：`docs.comfy.org` DAG 节点，`workflow/manager.py:732` `analyze_workflow/auto_detect_exposed_inputs/convert_save_format_to_api_format` + `converter_cli` 精准转换，已支撑 `WorkflowInspectorModal.tsx:80` 全量参数诊断。

**选型决策**：`tldraw SDK(自定义Shape+Binding)` 作自由画布层，叠加 `React Flow` 式端口连线语义。既保留 FigJam 自由排布，又支持 ComfyUI DAG 执行；比自研 Canvas 省 3~4 周。

## 5. 无限画布 v2（深度复用版）

### 5.1 目标：对标 MiniMax Design Canvas Flow + Lovart ChatCanvas

- **画布即工作流**：剧本拆解→角色→分镜→生图/视频→TTS→3D→剪映 全部在画布节点完成，边排布边执行。
- **ComfyUI 即插即用**：任意工作流（含外部 `COMFYUI_WORKFLOWS_DIR` 直读）可作为节点，暴露输入自动生成端口。
- **导演Agent 画布感知**：Agent 能看见全画布（`canvas_summary`），可新建/连线/执行节点。

### 5.2 画布核心能力（取 Miro/FigJam/Milanote/Canva 并集）

- 无限平移`Space+拖拽`、滚轮缩放 0.05~20x、惯性、`Ctrl+0` 回正
- 框选多选、成组 `Ctrl+G`、对齐（左/中/右/等距）、层级 `zIndex`、锁定/隐藏
- 连线：直线/贝塞尔/正交，端口磁吸，箭头/双向、标签注释，自动避障
- 物件：文本/便签/图片/视频/文件上传/粘贴 `Ctrl+V`、便签换色
- 历史 50 步、撤销/重做、小地图+鸟瞰导航、演示路径（按 `x` 排序逐帧聚焦）
- 快捷：`Ctrl+D` 复制、`Del` 删除、`Ctrl+A` 全选

### 5.4 连线语义与执行引擎

**数据类型**：`prompt(string)` `image(url|storagePath)` `video(url)` `audio(url)` `character(Character)` `camera(CameraPrompt)` `asset(Asset)` `brief(string)`

**连线校验**：同类型才可连；`image→image` 自动 `upload_image_to_comfyui` 转文件名；`prompt→prompt` 字符串拼接传入。

**执行引擎 `server/app/canvas/engine.py` (新增)**

- 输入：`canvas snapshot`（tldraw JSON + 节点 `props.workflow_id/props.prompt`）
- 流程：拓扑排序 DAG → 按依赖依次 `mcp_registry.execute_tool` / `image_registry.generate` / `video_registry.generate`，结果回写 `node.data.result`，通过 `WS /api/v1/ws/canvas/{project_id}` 推送 `tool_calling/tool_result` 前端局部刷新
- 模式：`选中节点单独执行` / `从此节点执行下游` / `全画布执行`

**一键转漫剧**：工具栏 `生成分镜序列` 将 N3 按 `x` 排序 → `PUT /api/v1/projects/{id}/content {scenes:[...shots]}` 打通 Creative→Production。

### 5.5 导演Agent 画布感知（对标 Lovart MCoT + MiniMax 多Agent）

- 前端 `store.listen` 将 `canvas_snapshot` 摘要（节点标题+位置+连线，脱敏截断 ≤2k tokens）随 `context.canvas_summary` 发往 `POST /api/v1/agent/chat` / `ws/agent`
- 后端 `AGENT_SYSTEM_PROMPT` 追加 `画布上下文` 段，Agent 可返回 `tool_calls` 含 `create_node/update_node/connect_nodes/execute_node` 前端执行 `editor.createShape/batch`
- 示例指令：`“把选中3个角色生成三视图并连到分镜3”` `“用工作流 xxx 重绘选中的5张图”` `“按赛博风格给我搭个情绪板”`

## 9. 校验标准

- 空项目可直接进画布与分镜工坊
- 跨项目资产可见性符合 `scope/shared_to` 规则
- 任意 `storage/workflows` 或 `COMFYUI_WORKFLOWS_DIR` 工作流可在画布内生成端口并成功出图
- Agent 能基于画布摘要创建/连线节点并触发执行

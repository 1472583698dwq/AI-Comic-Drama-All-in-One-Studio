## 6. 兼容与安全要求

### 6.1 兼容要求

- **存量数据迁移**：`Project` → `ProjectContent` 与 `asset.scope` 双重兼容，首次启动自动迁移。
- **会话格式**：`SESSION_FORMAT_VERSION = 1`。
- **工作流结构**：`WORKFLOW_SCHEMA_VERSION = 4`。
- **Agent 引擎可回退**：`AGENT_ENGINE=v2`（默认）/ `v1`（langchain_engine 保留）。
- **旧入口**：`client/src/mobile-main.tsx` 已下线（`vite.config.ts:23-27`），不要据此新增移动端页面。

### 6.2 安全要求

- **Origin 白名单**：`POST /api/v1/mcp/call`、`POST /api/v1/extensions/execute` 仅接受本机 Origin，否则 403（`_origin_guard` 中间件）。
- **trusted 模式**：`STUDIO_TRUSTED_MODE` 默认 `0`；开启后仍需逐源勾选 trusted。
- **密钥边界**：`.env` / `config_store.json` 仅存本机，**不进云同步白名单**。
- ⚠️ **已知风险**：`OPENLIST_*` 默认账号密码随仓库分发（`.env.example` 内明文），拿到代码者可读写该存储。**建议**：在使用方 `.env` 中覆盖为自有受限账号，或关闭 `OPENLIST_SYNC_ENABLED`。

### 6.3 对外提供 MCP 服务

默认 `STUDIO_HOST=127.0.0.1`，MCP 端点只在**本机**可访问。需要局域网/公网接入时：

1. 在 `.env` 设置监听地址与端口：`STUDIO_HOST=0.0.0.0`、`STUDIO_PORT=8000`。
2. **必须**设置 `STUDIO_MCP_AUTH_TOKEN=<随机长串>`；设置后所有 `/mcp-server` 请求都要带：
   ```http
   Authorization: Bearer <STUDIO_MCP_AUTH_TOKEN>
   ```
3. 公网访问走 HTTPS 反向代理或隧道，不要直接暴露 8000；同时限制来源 IP。
4. MCP 客户端地址：`http://<host>:<port>/mcp-server/`（Streamable HTTP）。

> ⚠️ `/mcp-server` 暴露的是真实工具集：生成、注册/删除生成源、文件读取、可信模式下的 `shell_exec` 等。没有 Token 时任何人只要能访问端口，就能消耗 API 额度或改配置。`STUDIO_MCP_AUTH_TOKEN` 只保护 MCP 端点；REST API 仍无登录鉴权，因此**默认不要监听 `0.0.0.0`**。

# 一键绑定方案（人物/素材 → 生成源参考列表）

> 状态：**P0/P1 已落地，P2（画布）已接**。核心纯函数 `client/src/components/storyboard/referenceBinder.ts`。

## 1. 目标

在分镜工作台与画布节点提供「⚡ 一键绑定」：把当前镜头/节点已绑定的人物 + 场景 + 道具/背景 + 白模预演 + 角色参考音频，按**所选生成源自身声明的参考插槽**（`input_schema`）自动填入参考列表，写入 `shot.dynamic_inputs`（画布写 `node.data`）。

- 默认**仅填空槽**（不动手工值）；预览抽屉可切**覆盖重绑**
- 缺口（必填未满足）/ 超限（maxItems 截断）/ 残留（源不认的旧键）可视化
- 支持撤销（单镜/批量分别记录 diff）

## 2. 架构

```
资源池 collectResources(shot, project, projectAssets, kind)
        │  图片：真首帧(i2v) > 角色主图(front>3q>side>avatar) > 场景底图 > 道具/素材 > 白模截图
        │  音频：说话角色 ref_audio_url > 旁白角色 > 其余绑定角色
        ▼
槽位声明 extractSlotsFromProvider(def, kind)   ← 唯一解析口径（x-handle/x-slot/maxItems/x-role）
        ▼
planBinding(resources, slots, current, {overwrite}) → { patch, filled, gaps, truncated, stale }
        ▼
写入 shot.dynamic_inputs（归一键 + 源真实键双写），生成时 keepDeclaredOnly 自动透传
```

## 3. 分配规则（确定性）

1. `first_frame` 语义槽：只放真首帧（`shot.image_url`），且仅 i2v（直出/r2v/t2v 不注入）
2. `last_frame` 语义槽：暂无自动来源，保留手工值；必填且空 → `gaps`
3. 音频槽：按 maxCount 取 说话角色 → 旁白 → 其余绑定角色，去重
4. 图片数组槽：角色主图（按 `character_ids` 顺序）→ 场景 → 道具 → 白模，去重后按 maxItems 截断
5. 双写：`x-slot` 归一键 + `originalKey` 源真实键同时写入；角色权值/文字标签沿用既有通道（`character_weights` / `promptWithCharacterTags`）
6. 仅填空槽模式：已有值的槽保留并占用其 URL，避免同一资源重复进其他槽

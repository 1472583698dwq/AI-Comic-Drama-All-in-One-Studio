## 1. 系统一句话理解

**MiniMax AI 漫剧 Studio** 是 `React19+Vite+Tailwind+Three.js+@xyflow` 前端与 `FastAPI+FastMCP+httpx` 后端的双工作台套件：**漫剧制作**（项目/分镜/3D/时间线/导出）+ **创意设计**（无限画布 DAG）。

核心流：`小说 → script_agent.parse_novel_to_project (MiniMax/DeepSeek)` → `角色三视图` → `分镜卡(image/video/audio)` → `3D导演台` → `剪映草稿`。所有生成能力经 `ProviderRegistry` 统一调度，导演 Agent 经 `MCP` 暴露，画布 `DAG` 可视化编排。

```
client: React19+Vite+Tailwind+Three.js+@xyflow → REST/SSE/WS → server: FastAPI+FastMCP → MiniMax/DeepSeek/ComfyUI/HTTP Provider + pyJianYingDraft
```

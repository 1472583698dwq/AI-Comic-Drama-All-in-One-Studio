## 1. 系统一句话理解

**MiniMax AI 漫剧 Studio** 是 `React19+Vite+Tailwind+Three.js+@xyflow` 前端 与 `FastAPI+FastMCP+httpx` 后端 的双工作台（**漫剧制作**：项目/分镜/3D/时间线/导出；**创意设计**：无限画布）创作套件。

核心流：`小说 → script_agent.parse_novel_to_project (MiniMax/DeepSeek)` → `角色三视图` → `分镜卡(首帧 image + 视频 video + 配音 audio)` → `3D导演台` → `剪映草稿`。所有生成能力经 `ProviderRegistry` 统一调度，导演 Agent 经 `MCP` 暴露，画布 `DAG` 可视化编排。

## 2. 本次修复要点（对比截图）

### 2.1 视觉：主题跟随系统
- **问题**：`ProviderNode` `bg-surface-secondary #f2f2f5` 配 `text-white` 对比度 1.3:1，`placeholder-gray-500` 在浅底不可读。
- **修复**：`client/src/index.css:37` 已定义 `tokens --surface/--foreground/--border` 的 `dark/light` 双值，节点改 `bg-[var(--color-surface)] text-[var(--color-text-main)]`，头部固定 `bg-zinc-900 text-white` 高对比，`Handle` 直径12 `border-2 white` 色码 `image/violet video/orange audio/pink text/sky` 随主题发光。`useThemeStore` 监听 `prefers-color-scheme` 切换 `data-theme`。

### 2.2 生成源：从固定到全动态
- **问题**：截图 `AutoDL MiniMax` 显示 `暂无结构化参数 (将使用默认 prompt/size/seed)`，`params_schema` 为空时无输入。
- **修复**：`server/app/api/provider_routes.py:20 _default_params_schema(kind)` 兜底：`image: prompt/negative/width/height/steps/cfg/seed`，`video: prompt/duration/resolution/fps`，`audio: text/voice/speed/pitch`。若 `OpenAPI/cURL/文档` 经 `LLM` 解析出真实 `input_schema`（含 `reference_images: array uri x-handle:image` 等多图/多音），则直接采用。前端 `ProviderNode.tsx:159` `ProviderParamForm` 遍历 `params_schema.properties` 渲染 `number/text/select/image[]`，`保存参数到Provider` `PUT /providers/{id}`。

### 2.3 连线：有向多模态
- **前**：单 `!w-3` 橙点，无标签，`comfyui` 等内置与自定义割裂。
- **后**：`ProviderNode/ShotCard/Video/TTS` 共用 `client/src/components/canvas/utils/dynamicHandles.ts: handlesFromSchema()`，`x-handle` 推断类型，`onConnect` 按类型校验，边 `smoothstep` 中点标签 `prompt→prompt` 可点改 `x_mappings`，`canvas/engine.py:46 collect_upstream` 按 `x-handle` 聚合 `image[]/audio[]/prompt`。

### 2.4 分镜：去乱
- **前**：右栏 `340px` 内 `ProviderPicker+Workflow+Video+TTS` 堆叠。
- **后**：`ShotInspector.tsx:570` 改 `Tab 台词|画面|视频`，`台词` 内 `ProviderPicker kind=audio`+`ProviderParamForm`，`画面` 内 `ProviderPicker kind=image` 与 `Workflow` 互斥，`Video` 同理；`textarea auto-resize` 复用 `AutoTextarea.tsx`。

### 2.5 设置可见
- **问题**：自定义源仅画布可见，设置不可见。
- **修复**：`ConfigView.tsx:22` 新增首位 `Tab providers`，`loadProviders()` 复用 `GET /providers?kind` 全域，卡片展示 `kind/URL/模型/健康/参数数`，`Header Plug` 模态 `ProviderManagerModal.tsx` 与设置 tab 双入口 `provider-list-refresh` 同步。

## 1. 产品定位与目标

**一句话**：长篇小说 → 一键成片。以「总导演 Agent + 专家子代理集群」并行编排，覆盖 拆解 / 定妆 / 生图 / 图生视频 / 配音 / 导出剪映 全链路。

### 1.1 本期目标（Goals）

| 编号 | 目标 | 衡量方式 |
|---|---|---|
| G1 | 打通「小说 → 成片」一键链路，单点失败不阻塞全片 | 一键成片任务可从 `POST /api/v1/onekey/run` 提交并产出可播放 MP4 |
| G2 | 让生成结果**可预期**：任意生成源可测试连通、参数可预期、失败有明确错误 | 生成源「测试」返回明确状态；未联通源不出现在可选项 |
| G3 | 让工作台**易用**：桌面专业版（3D 导演台 + 多轨时间线）与移动卡片流双端可用 | 双端均可完成"逐镜微调 + 合片" |
| G4 | 建立**可扩展**的插件与扩展体系（13 类扩展点） | 插件包可安装/启用/禁用/卸载且精确回滚、热生效 |
| G5 | 工程可交接：文档、接口、测试证据成体系 | 五类上下文文档齐备（见 `文档索引.md`） |

### 1.2 评估维度（沿用测试用例集口径）

- **视频质量**：画面、连贯性、音画同步。
- **使用体验**：易用性、流畅度、可预期性。

## 2. 范围（Scope）

### 2.1 核心范围（In Scope）

| 模块 | 内容 | 关键实现 |
|---|---|---|
| 一键成片 | 总导演 Agent 规划 + 子代理并行扇出（batch / 后台提交 + 收口）、导演组切换、`qa_gate` 质检门 | `server/app/pipelines/`、`server/app/api/onekey_routes.py` |
| 桌面专业版 | 3D 虚拟导演台（Three.js）、多轨时间线、角色一致性资产库 | `client/src/components/director3d/`、`timeline/`、`character/` |
| 移动端卡片流 | 整章粘贴 → 拆解；9:16 卡片流逐镜微调 | `client/src/components/mobile/MobileCardFlow.tsx` |
| 生成源体系 | 图像/视频/音频/素材多源，测试连通、参数暴露规范 | `server/app/api/provider_routes.py`、`docs/自定义源标准_参数与输入暴露规范_v1.md` |
| 扩展与插件 | 13 类扩展点、插件包生命周期、扩展中心 | `docs/plugin-dev.md`、`server/app/extensions/`、`server/app/plugins/` |
| 画布与工作流 | 无限画布、声明式画布节点、ComfyUI 工作流路由 | `client/src/components/canvas/`、`server/app/api/canvas_routes.py` |
| 导出与同步 | 剪映草稿导出、时间线合片、素材与工程云同步（OpenList） | `server/app/api/timeline_routes.py`、`server/app/storage_sync/` |
| MCP 生态 | 内置 MCP 中枢 + 外部 MCP Server 接入 | `server/app/mcp/`、`/mcp-server` |

### 2.2 交付形态

- **Windows 桌面版**（推荐最终用户）：PyInstaller 独立包 + WebView2（pywebview，回退 Edge/Chrome App 模式），双击即用、无黑框。
- **源码开发模式**：后端 `python run_server.py`（127.0.0.1:8000）+ 前端 `npm run dev`（localhost:5173）。
- **系统要求**：Windows 10/11 64 位。

## 3. 优先级

沿用测试用例集与设计方案的口径：

- **P0（阻塞发布）**：核心链路。含 一键成片主链路、`/videos/generate` 与 `/images/generate` 基础生成、配置与生成源可用性、项目/素材 CRUD。
- **P1（重要功能）**：端到端质量链路、TTS 配音、时间线合片、剪映导出、扩展/插件启停、画布执行。
- **P2（次要/增强）**：性能、体验打磨、审计与遥测、边缘参数。

> 优先级定义来源：`测试用例_2026-10-05/README.md` §三、`docs/设计方案_v2_双工作台_无限画布.md` §7 实施分期。

## 7. 依赖与约束

- **外部依赖**：各生成源 API Key（文本/图像/视频/配音）、ComfyUI（`127.0.0.1:8188`）、OpenList（云同步）、剪映（草稿导出）。
- **兼容约束**：
  - 存量数据兼容：`Project` → `ProjectContent` 与 `asset.scope` 双重兼容，首启自动迁移。
  - 会话格式 `SESSION_FORMAT_VERSION=1`、工作流 `WORKFLOW_SCHEMA_VERSION=4`。
- **安全约束**：`POST /api/v1/mcp/call` 与 `POST /api/v1/extensions/execute` 有 Origin 白名单校验（非本机 Origin → 403）；`storage/config_store.json` 与 `.env` 仅存本机。

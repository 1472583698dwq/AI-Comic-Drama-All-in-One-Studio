### 2.1 逐项利弊

#### MinimalNodes.tsx
- **本地独有**：`AgentShell` 渲染「会话」绿标（依赖 `agentFocusNodeIds`）；`PromptNode` 目标句柄 `id="prompt_in"`；`VideoGenNode` 简易播放（无 `controls`/无错误提示/按钮未显式居中/无 `nodrag`）。
- **上游新增**：句柄 id 改回 `prompt`（修「文本连入不可见/不向下游传播」）；`mediaError` 红层 + `onError/onPlay/onPause` + `controls:true`；播放按钮显式居中 + `stopPropagation` + `nodrag`。
- **利弊**：
  - 取本地 → 得「会话」徽章；**但** `prompt_in` 与当前 `nodeRegistry`（`'prompt'`）冲突，属**运行期回归**；视频节点丢健壮化。
  - 取上游 → 句柄与注册表对齐、视频节点健壮；丢「会话」徽章（`agentFocusNodeIds` 在当前主干仍存在，可单独挑回）。
- **结论：挑段**（上游 handle/视频 + 可选挑回会话徽章）。冲突面小（不同区块）。

#### ProviderNode.tsx
- **本地独有**：内联「快速创建」表单（name/lang/code/key + 载模板 + 直接 `POST /providers`）；测试/保存用原生 `alert`。
- **上游新增**：监听 `provider-created`（创建后自动刷新并选用新源）；快捷创建改为三个按钮派发 `open-provider-create`（文档/代码/ComfyUI 三 tab，`select:true`）；`alert`→`toast`。
- **利弊**：取本地 → 画布内可就地写代码，但丢三种创建方式与「创建后自动选用」（该监听被其他链路依赖）；取上游 → 创建入口统一到新建源弹窗、体验更好，代价只是"写代码时多一次弹窗"。
- **结论：取上游。**

#### CharacterStudio.tsx
- **本地独有**：**三视角编辑器**（正面 / 侧面 90° / 3-4 45° 三张卡，各自「从素材库导入」「清除此视角」+ 用途说明），生成回调写 `three_views.side/three_quarter`。
- **上游新增**：`AutoRatioMedia` 统一媒体展示；收敛为单张「三视图」卡，只保留 `front`。
- **利弊**：取本地 → 保住**角色一致性的第二个/第三个生产槽**（共享模块 `referenceBinder.characterMainImage`、`shotReference.boundCharRefs` 仍按 `front>avatar>three_quarter>side` 读取，本地三视图会被正确消费），代价是原生 `<img>` 无自适应比例；取上游 → 视觉统一、代码更短，但**生产槽从 3 个缩到 1 个**，与本地素材库文案（"去该页补三视图与参考音频"）语义不符。
- **结论：挑段**（本地三视角结构 + 把 `<img>` 换 `AutoRatioMedia`）。若判定只要单张三视图 → 取上游。

#### AssetLibrary.tsx
- **本地独有**：发到分镜后落 `setActiveTab('canvas')`；无文本分类。
- **上游新增**：`'text/提示词'` 分类 tab + 新建文本素材（正文进 `content`）+ 文本卡片与详情；**拖拽 payload 扩展** `application/canvas-assetkind=text` / `application/canvas-text`（供画布建/填文本节点）；落点改 `setActiveTab('studio')`。
- **利弊**：取本地 → 落点直达画布，但**丢整条"文本/提示词素材"能力**，且与"分镜台走上游"不一致；取上游 → 拿到文本素材能力，但落点是 `studio`（默认关 → 走 `resolveTab` 回落首个可用页，不是画布）。
- **结论：挑段**（取上游主体；如需"发到分镜"直达画布，把那 2 处落点改成 `'canvas'`）。注意：改落点**不**等于恢复文本投放能力，见 §3.1。

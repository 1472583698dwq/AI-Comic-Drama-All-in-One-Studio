Verdict

怎么选

按使用场景给出推荐；本项目那条在最前面，其余 7 条来自原横评。

要桌面一体化：一句话集群式出片，再逐镜精修，导出真实剪映草稿
本项目 MiniMax AI 漫剧 Studio

总导演 Agent + 专家子代理并行扇出的一键成片（带 qa_gate 质检门），分镜台 / 无限画布 / 3D 导演台 / 多轨时间线在同一工作台；pyJianYingDraft 真实剪映草稿（画面 / 配音 / 字幕 / BGM 多轨）+ MP4 合片；模型接入最宽（图片 / 视频 / 音频 / LLM 全可自定义，含 IndexTTS 等 5 家音频与音色克隆）；13 类插件扩展与 FastMCP 全家桶；Windows 桌面 exe + WebView2 与移动端卡片流为独有交付形态。短板：无多集管理、无金额报表、未声明 License。

要最完整的分镜工作台：逐镜编辑、首尾帧、版本、时间线
04 BigBanana（次选 07 ArcReel）

分镜表、宫格、首尾帧、提示词都能逐镜编辑，内置 CutOS 时间线并能导出剪映草稿，资产一致性控制最细。缺点：模型只能走它家 AntSK，自定义模型要买商业版，协议禁止商用。

自托管、模型随便接、花多少钱看得见，最后交给剪映精修
07 ArcReel

可以用声明式端点编辑器加 ComfyUI workflow 接入几乎任何模型。每个生成按钮前都标出单价，并按集统计花费，产物过期会提示、关键环节要人工确认，支持导出剪映草稿。协议是 AGPL：对外提供服务需要公开修改后的源码。

多角色一致性、构图要可控
05 DramaClaw

分两步出分镜：先画荧光色块草图摆姿势，再锁定角色身份出图；宫格视图和抽卡挑选两项都是满分。另有主线流程和画布两条路可以互相切换，具备的功能也最多（31 项），代价是上手成本高。协议是 Elastic 2.0，不能包装成 SaaS 对外提供。

在画布上自由编排，加 3D 预演，并且能商用
01 Toonflow

节点画布配 Agent（有 18 个画布工具），带 3D 导演节点、插件市场，还能作为 MCP 服务器被外部调用，可以上传 .ts 适配器接入任意模型，MIT 可商用。缺点：没有时间线剪辑，也没有登录。

一句话交给 Agent，自动出片
03 ViMax

按机位树分组镜头、让模型自动挑参考图来保持一致性，小说先检索再拆成场景，MIT 协议。缺点：只出横屏，重渲单个镜头实际不生效，上传的参考图不会用于生成，没有配音和剪辑。

和 AI 对话反复改，每个产物都能追到来源
02 waoowaoo

画布就是文件树，连线显示每张图、每段视频由谁生成；每个项目有一个独立沙箱里的 Codex Agent。缺点：只能用 OpenRouter，文档只读，没有时间线、配音和导出。

用 Seedance 多参考最快出带对白的视频
06 huobao-drama

资产图直接当参考图，每个分镜段落直接出 8–15 秒带对白的视频，一个 Key 就能配好全部模型，Agent 提示词也能在线改。缺点：没有分镜图和首尾帧审图，没有字幕和配音，协议禁止商用。

要做成商业产品
01 Toonflow / 03 ViMax（MIT）

02 和 05 是 Elastic 2.0：公司内部可以商用，但不能包装成托管服务对外提供。07 是 AGPL，对外服务必须开源修改。04 和 06 是 CC BY-NC-SA，禁止商用。本项目尚未声明 License，开源发行前需先补。（横向对比里，直接采用 MIT / Apache-2.0 即可在商用自由度上超过以上多数项目。）

Vs. the field

领先与短板

把本项目的 46 格与 7 款开源项目逐行对照后的结论。

领先项 · 7 家没有的组合

  • 总导演 Agent + 子代理集群：同质任务批量扇出、长耗时视频后台提交、失败隔离，另有可扩展导演组与 qa_gate 质检门；7 家中独此一份（ArcReel / waoowaoo 的 Agent 是单点对话式）。
  • 画布 + 3D 导演台 + 多轨时间线三件套同仓：Toonflow 无时间线/分镜表，BigBanana 无画布/3D，DramaClaw 无真时间线、CE 无一键成片。
  • 3D 导演台更进一步：白模预演视频录制后回灌成视频参考、导演包 GLB 道具/环境、MCP 运镜规划（20+ 轨迹）；仅 Toonflow 可比但无预演回灌。
  • 13 类扩展注册表 + 插件 zip 生命周期（安装/启用/精确回滚/热重载）+ FastMCP 40+ 工具 + 标准 /mcp-server 对外挂载；扩展体系比 Toonflow 插件市场、ArcReel skills 更系统。
  • 模型接入最宽：15+ 预置通道（图片/视频/音频/LLM），支持从 API 文档 / cURL / OpenAPI 智能生成代码源；ComfyUI 工作流直读 + 参数槽位。IndexTTS / CosyVoice / GPT-SoVITS 音色克隆是 7 家都不具备的。
  • 真实剪映草稿（pyJianYingDraft 多轨：画面/配音/字幕/BGM，逐镜时间线回执）+ MP4 合片 + 项目包 zip。
  • 独有交付形态：Windows 桌面 exe（WebView2、双击无黑框）+ 移动端卡片流 + OpenList 素材云同步；7 家均为自托管 Web/Docker。
  • 提示词可见可改 5 分并列第一：合成提示词、最终提示词预览、AI 润色，且提示词即生成请求。

短板项 · 按修复优先级

  • P0 · 多集/分集管理 = 0 — 7 家全部具备（3–5 分），只有本项目无 episode 层（Project→Scene→Shot）。连载漫剧的结构性硬伤。
  • P1 · 世界观/设定集 = 2 — 只有画布 proposal/brief 雏形，无设定集实体（BigBanana 5 分、waoowaoo 3 分）。
  • P1 · 费用/用量统计 = 2 — 已有 gen_timings.jsonl + token 计量，缺价格表与金额报表（ArcReel 5 分杀手锏）。
  • P1 · 版本历史/回退 = 3 — 1镜4抽、候选定版、history 字段都有，缺浏览/回退 UI 与审片-重抽闭环（DramaClaw 5 分）。
  • P2 · 小说导入与拆章 = 2 — 只能粘贴文本，缺 txt/md/docx/epub/pdf 解析与拆章（ArcReel 5、BigBanana 4）。
  • P2 · 宫格/缩略图墙 = 3 — 分镜台只有列表卡，无宫格模式（DramaClaw 5 分）；一键成片有缩略图墙可部分代偿。
  • P2 · 字幕 = 3 / 导出 = 4 — 剪映字幕轨 OK，但无 SRT 独立导出、无 FCPXML/EDL（导出器框架已具备扩展位）。
  • P3 · 场景/道具独立管理页、尾帧生成入口、音效库、对口型 = 0（对口型 7 家最高也才 2 分，属行业普遍短板）。
  • P4 · License 未声明 / i18n = 0 — 开源发行前必须补；全 UI 中文硬编码。

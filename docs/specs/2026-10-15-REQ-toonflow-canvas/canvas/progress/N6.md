## 每个节点：改了什么 / 宿主（H1）要提供什么

### shot-card
- 逻辑：生成首帧 `apiService.generateShotImage`（项目画幅/风格、workflow_id、dynamic_inputs、provider‖provider_id、model）→ `image_url`；生视频 `generateShotVideo`（i2v、首帧 = image_url、5s）→ 有 task_id 时 `pollVideoTask` → `video_url`；人物/场景/道具徽章读 `useProjectStore` 里同 id 分镜（`shotId‖id‖节点 id`）。
- 换皮：标题栏外置；徽章改 `cv-la-chip`（场景 / 道具的 emoji 换成 Tabler 山 / 剑图标）；生成源、景别·运镜标签在卡片顶部；浮动工具栏「生成首帧 / 生视频」+ 下载 / 全屏（当前首帧）。
- 行为差异（都是修旧问题，不改语义）：数据只从 `data` 读（旧组件 `localData` 副本只在 provider 变时同步，外部写入的 image_url 不刷新）；`alert` 改全局 `toast`；「生视频」加了进行中状态。
- **H1**：连线时把 provider* 节点的 `provider_id / provider / model` 写进分镜卡 data（旧宿主 onConnect 的做法，卡片只认 data 里的值）；要让动态口出现，需要有人往 data 写 `definition / providerDef`（旧宿主也没写，现状不变）。

### comfy-workflow
- 逻辑：`listWorkflows('all')` 列内部 + 外部工作流；选中写 `workflow_id`；`inspectWorkflow` 的 exposed_inputs 生成表单，`default_value` 只补 `dynamic_inputs` 里没填过的键，改任何一项都把「默认值 + 已填」整份写回 `dynamic_inputs`（同旧口径）；「使用此工作流生成」`generateShotImage({prompt, workflow_id, dynamic_inputs, aspect_ratio:'9:16'})` → `result_url + dynamic_inputs`。
- 「参数与诊断」照旧派发 `window` 事件 `open-workflow-inspector`（App.tsx → `modalIntents.openWorkflowInspector`）。
- 换皮：原生 select 外观对齐 el-select（键盘 / 无障碍由浏览器提供）；标题栏「刷新」= 重拉工作流列表 + 重新 inspect；结果图可下载 / 全屏。
- 行为差异：切换工作流时旧工作流的表单立即消失（按工作流 id 记解析结果，不再短暂显示上一个工作流的输入）；垫图值是 ComfyUI 文件名（工作流默认值如 `ref.png`）时显示文件名标签而不是一张裂图；主提示词为空时先回落 **`prompt` 口上游文本**，再 image_prompt / 'masterpiece, high quality'（旧宿主连线时已把上游文本写进 data.prompt，结果一致；新宿主不写时也能用），输入框占位提示显示上游文本。
- **H1**：App.tsx 的 `open-workflow-inspector` 监听保留即可。

### 共同
- 写数据一律 `useKitNodeActions(id).update`（→ 宿主 `updateNodeData`，缺省 React Flow）；没有用 `data.onUpdate / data.onExecute`，也没用 `actions.execute`（这几个节点的按钮原本就直接调 apiService，不经 handleNodeExecute）。

## kit 使用中注意到的点（请协调人判断是否改 kit）
1. `createNodeData` 无条件写 `label: def.label`：缺省标题要现算的节点只能靠 `defaultData` 返回 `label: ''` 覆盖（本目录已这么做）。
2. NodeSkeleton 的 `onContextMenu` 不看 `defaultPrevented`，节点里 portal 出去的弹层（全屏编辑器等）右键会冒泡打开节点菜单；本目录用包一层 `stopPropagation` 解决。
3. FloatingToolbar 无论有无产出都画「下载」（Toonflow 同款，置灰）；export / timeline-export 这种无产出节点也会显示一个灰色下载钮。

## 遗留 / 说明

- 2 秒片段在卡片上会和下一段重叠约 12px：`MIN_CLIP_PX=64` 大于 2s×26px/s，原 TimelineStrip 同样如此（布局算法原样保留）。
- 原 `TimelineStrip` 调用 `rulerStepForPx(frameTotal, pxPerSecond)` 传错了参数顺序；移植版改成 `rulerStepForPx(pxPerSecond)`，卡片 / 全屏两种像素密度下结果相同（都取整秒刻度），无可见变化。
- 合片产物名是「`<项目>_5s成片_成片.mp4`」：后端 `_reserve_output_path` 自己再拼一个「_成片」，既有行为，未动。
- comfy 垫图仍以 dataURL 存进 `dynamic_inputs`（既有行为，大图会让画布 JSON 变大）。

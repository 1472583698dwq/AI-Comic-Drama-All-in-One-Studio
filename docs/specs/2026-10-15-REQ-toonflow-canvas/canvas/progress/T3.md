### 精简舞台（`scene/stageCore`）

```ts
createMiniStage(container: HTMLElement, opts?: MiniStageOptions): MiniStage

interface MiniStageOptions {
  environment?: StageEnvironment | 'plain'        // 默认 'plain'（深色地面 + 网格）
  castLayout?: CastLayout | string; pose?: PosePreset   // 默认 solo / stand（castMembers 同源）
  cast?: MiniStageMember[]                        // { entity?, role?, pose?, accentColor?, position?, rotationY?, joints? }
  camera?: StageCameraState                       // 或 framing / focalLength / cameraRoll（默认 medium 35mm）
  framing?: string; focalLength?: number; cameraRoll?: number
  aspect?: number                                 // 画幅（宽/高）：容器内等比留边渲染，导出与所见一致
  lighting?: Partial<LightingConfig>; pixelRatio?: number
  interactive?: boolean                           // 默认 true：左键空白=环绕、右/中键=平移、滚轮=推拉、左键关节=拖关节(Shift=扭转)
  isLocked?: (entity: string) => boolean
  onJointsChange?: (entity: string, joints: MannequinJointPose) => void   // 关节拖完（有转动）
  onCameraChange?: (state: StageCameraState) => void                    // 轨道/平移结束、滚轮停 200ms、setCameraState、applyFraming
  onSelect?: (entity: string | null, jointId?: string) => void
}

interface MiniStage {
  container; scene; camera; renderer; entities         // three 对象（只读引用）
  render(): void; invalidate(): void; resize(): void; setAspect(aspect?: number): void   // 按需渲染，无常驻循环
  setEnvironment(env): void; setLighting(cfg: Partial<LightingConfig>): void
  setCast(castLayout, pose, joints?: MannequinPose['entities']): void
  addMannequin(member: MiniStageMember): THREE.Group; removeEntity(entity): void
  listEntities(): string[]; getEntity(entity): THREE.Object3D | undefined
  getMannequinPose(): MannequinPose                   // { v: 1, entities: { [entity]: { joints } } }，即分镜 mannequin_pose
  getJoints(entity): MannequinJointPose; setJoints(entity, joints): void
  applyMannequinPose(pose): void                      // 与 3D 片场 agent-stage-patch 同语义：给到的实体叠加，没给到的复位
  resetJoints(entity?): void
  getCameraState(): StageCameraState; setCameraState(state, opts?: { silent?: boolean }): void
  applyFraming(framing, focalLength = 35, rollDeg = 0): StageCameraState
  exportSize(opts?: { width?; height?; longEdge? /*1280*/ }): { width: number; height: number }   // 偶数宽高
  snapshotPNG(opts?: { width?; height?; longEdge?; type?; quality?; camera?: StageCameraState }): Promise<Blob>
  recordCameraPath(keyframes: CameraKeyframe[], durationSec?: number, fps = 30,
    opts?: { width?; height?; longEdge?; mimeType?; videoBitsPerSecond?; signal?: AbortSignal; onProgress?: (p: number) => void }): Promise<Blob>
    // 实时录制（耗时≈时长）；优先 MP4(H.264)，不支持退 WebM，看 blob.type；页面隐藏时报错
  dispose(): void                                    // 释放几何/材质、WebGL 上下文、移除画布
}
pickRecorderMimeType(): string
```

N5 接入要点：
- 容器加 `nodrag nowheel nopan`，否则画布会抢拖拽/滚轮。
- 导出用的是**离屏渲染器**（用完立刻 `dispose + forceContextLoss`），不影响节点里的视图；画布上多个 3D 节点时建议只给选中/可见的节点挂舞台（浏览器 WebGL 上下文上限约 16）。
- 关节姿态存节点 data 时直接存 `getMannequinPose()`，与分镜 `mannequin_pose` 同结构，「在 3D 片场打开」可无损带过去。
- 典型导出：`stage.recordCameraPath(motionPresetKeyframes(motion, stage.getCameraState(), { speed }), undefined)`。

## 遗留 / 提示

- `public/models/BoomBox.glb` 是截断文件（赛博影棚会自动放它），每次进 3D 片场都会打一条告警；与本任务无关，需要重新下载该模型。
- `motionPresetKeyframes` 的环绕类按「绕注视点」计算，和 3D 片场模拟（绕世界原点、以 startPos.z 为半径）在默认机位下一致，机位被拖离 +z 轴后片场原逻辑会跳位、关键帧版本不会；片场本身未改（保持行为不变）。
- 迷你舞台不含道具与 GLB（N5 需要时可用 `scene/props`、`scene/glb` 自行 `entities.add(...)` 后 `invalidate()`）。

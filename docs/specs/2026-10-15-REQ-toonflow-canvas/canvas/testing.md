# REQ-toonflow-canvas · 端到端测试用例

环境：隔离实例 前端 `http://127.0.0.1:5180`、后端 `http://127.0.0.1:8001`（worktree storage）。浏览器自动化执行；每条记录 通过/失败/阻塞 + 截图。
真实生成用本机已配置的生成源；生成源不可用时，生成类用例判「阻塞」并注明原因，不得伪造结果。

## A. 外观与画布交互
- A1 打开任一项目画布：点阵背景、节点标题在卡片外上方、卡片 12px 圆角无阴影、端口默认隐藏；悬停节点后端口出现。
- A2 深色 / 浅色主题切换：节点、连线、分组框颜色随主题变化，无写死的深色块。
- A3 滚轮平移、⌘+滚轮缩放（0.2–8）、拖动节点按 16 格吸附。
- A4 从「图片」节点输出拖线到空白处：弹出的节点菜单只列出能接收 IMAGE 的节点；选「视频生成」后自动连上。
- A5 拖线到类型不兼容的端口：端口变红、不能连上。
- A6 选中节点：相连的边高亮；点击一条边出现「断开」按钮，点击后边被删除。
- A7 框选 3 个节点 → 成组：出现分组框，可改名、四角缩放，拖动分组带动子节点。
- A8 双击节点标题改名；右键菜单的「创建副本」「删除」「保存到素材库」可用。
- A9 刷新页面后节点位置、分组、连线、标题都保留。

## B. 核心节点
- B1 文本节点：输入 Markdown 后切预览正确渲染；选「扩写」技能生成，结果流式写入。
- B2 文本节点连到图片生成节点：参考列表出现该文本；在提示词里插入 `{{ref 1}}` 显示为引用标签；拖拽调整两条参考的顺序后编号随之改变。
- B3 图片节点：上传图片 → 显示；全屏、下载可用；宫格切分 2×2 → 生成 4 个图片节点并自动排布。
- B4 图片节点标记 + 局部重绘：画标记后提交，调用图片生成源，新图进入历史版本。
- B5 图片生成：选生成源、比例 9:16，直接生成（智能规划关闭）→ 出图；再开启智能规划生成 → 面板显示规划出的生成源和参数。
- B6 图片生成历史：生成两次后可在历史里切回第一张，下游拿到的是当前版本。
- B7 视频节点：上传视频 → 截取当前帧/首帧/尾帧各生成一个图片节点；分离音轨生成音频节点；截取 1–3 秒生成新视频节点。
- B8 视频生成：两个图片节点连入，模式按规则自动匹配（生成源支持多参考时为「多参考」；只支持首帧/尾帧时为「首尾帧」）；手动切到「首尾帧」后两张图分别落到首帧、尾帧；生成后视频可播放；切换模式后参数随生成源变化。
- B9 音频节点：上传音频显示波形；截取、变速 1.5× 各生成新音频节点。
- B10 音频生成：选语音源（如 IndexTTS），输入台词生成；图片和音频参考合计连入第 2 个时被拒绝。
- B11 3D 导演：节点内舞台加载人偶，拖动关节；选景别/运镜预设后 `camera_prompt` 输出更新；连到视频生成节点后其参考列表出现该机位文本。
- B12 3D 导演：加两个运镜关键帧，导出 PNG → image 输出可连到图片生成；导出 MP4 → video 输出；点「在 3D 片场打开」跳转到 3D 片场页。

## C. 独有节点（换皮后功能不变）
- C1 分镜卡：显示角色头像、场景、道具徽章；在节点里生图可用。
- C2 ComfyUI 工作流：选工作流后自动生成参数表单。
- C3 时间线：连入 2 段视频，合成 MP4 可下载；导出剪映草稿可下载。
- C4 剧本拆解 + 灵感简报：简报连入剧本拆解，运行后输出角色、分镜。
- C5 代码节点（打开功能开关后）：按 input_schema 动态端口，运行成功。
- C6 扩展节点（示例插件 `upscale_ext`）：视频连入其 `video` 端口后，执行时能拿到视频（修复验证）。
- C7 生成源节点：选源、健康检测；下游拿到生成源 id。
- C8 以上所有节点外观与核心节点一致（标题在外、圆角、端口样式、颜色变量）。

## D. 迁移与兼容
- D1 打开含旧节点的画布（`text-prompt`、`video-legacy`、`tts`、`asset`、`load-image-batch`、具名端口连线）：自动迁移，内容、已生成结果、连线全部保留；`storage/projects/{id}/canvas_backups/` 出现原画布备份。
- D2 再次打开同一画布不再迁移（`schema_version: 2`），不重复备份。
- D3 未知类型节点显示「不支持的节点」卡片，保存后原数据不丢。
- D4 分镜台「在画布中运行」：自动建出的子图使用新节点，角色三视图、参考音频、白模正确绑定为参考；结果能写回分镜。
- D5 右侧画布 Agent：让它「新建一个图片生成节点并连上现有文本节点，然后生成」，节点和连线正确创建（`in` 端口），生成成功。
- D6 Agent 用旧端口名连线（如 `first_frame`）：被转换为 `in` + 槽位，视频生成用到正确的首帧。

## E. 回归
- E1 前端 `npx tsc -b` 0 错，`npx vitest run` 全绿（≥ 基线 90 + 新增）。
- E2 后端 `pytest` 除既有的 `test_skill_engine::test_default_scan_stays_inside_project` 外全绿。
- E3 其他页面（剧本、分镜台、3D 片场、素材库、导出中心、设置）正常打开，3D 片场的人偶和白模导出功能不受模块抽取影响。

# 02 端到端链路测试用例

> **生成日期：2026-10-05（今天生成）**
> 目标：验证"从创意到成片"的完整链路可用性与顺滑度——这是本平台的核心价值主张。
> 前置条件：后端已启动；已配置至少一套真实可用的 生图 + 视频 + TTS provider；`/timeline/engine` 自检通过。

---

## 模块 A：图→视频→配音 质量链路（手动 + 自动混合）

| 用例编号 | 标题 | 优先级 | 类型 | 步骤 | 预期结果 |
|---|---|---|---|---|---|
| E2E-001 | 生图→首帧→视频全链路 | P0 | 功能/质量 | 1. `/images/generate` 生成一张分镜图 2. 以该图为 `first_frame_url` 调 `/videos/generate`（i2v） 3. 轮询至成功 4. 播放成片 | 全链路无人工转接即可完成；成片首帧与生图一致、画面稳定、无明显畸变 |
| E2E-002 | 角色一致性（同一角色多分镜） | P0 | 质量 | 用同一角色三视图 + 相同 seed 生成 3 个不同场景分镜视频 | 三个视频中角色外观（发型/服装/脸型）保持可辨认的一致性 |
| E2E-003 | 视频+配音合成素材包 | P0 | 功能 | 同一分镜生成视频后，用对应台词调 `/tts/generate`，将两者在资产库关联 | 视频、音频均入库，时长可对齐，可供合片使用 |
| E2E-004 | 首帧+尾帧连贯叙事 | P1 | 质量 | 分别生成首帧图与尾帧图（同一场景不同时刻），i2v 带双关键帧生成 | 成片从首帧自然过渡到尾帧，无跳变/闪烁 |
| E2E-005 | 参考视频驱动的 r2v | P1 | 质量 | 提供一段真人运镜参考视频，`mode=r2v` 生成 | 成片运镜风格与参考视频相似度可接受 |
| E2E-006 | 多 provider 同 prompt 横评 | P0 | 质量 | 相同 prompt/时长/分辨率分别在 minimax_h3、seedance、kling、wan3、openai_video 生成 | 各 provider 均成功出片；按 03 号文档评分表横评画质/运动自然度，产出选型建议 |
| E2E-007 | 断点续用：生成后刷新页面 | P1 | 体验 | 任务运行中刷新前端页面 → 重新进入 | 任务状态仍可从 `/videos/status` 恢复显示，不出现"任务消失" |

## 模块 B：一键成片（POST /api/v1/onekey/run + 轮询）

| 用例编号 | 标题 | 优先级 | 类型 | 步骤 | 预期结果 |
|---|---|---|---|---|---|
| OK-001 | 默认链路全流程 | P0 | 功能 | 1. POST `/onekey/run` 提交一段短剧本 2. 轮询 `GET /onekey/tasks/{task_id}` 直至终态 | 依次完成 style_lock → split → role_image → scene_image → shot_image → shot_video → shot_voice → export → summary/review；终态为成功 |
| OK-002 | 分镜视频 pending 回填 | P0 | 功能 | 运行中观察 `shot_video` 阶段 | 每个分镜视频任务被登记为 pending 并由 `_sync_pending_videos` 轮询回填，最终所有分镜均有 video_url |
| OK-003 | 中途失败的部分产出保留 | P1 | 异常 | 让 shot_image 阶段某一张生图失败（如临时改坏生图 key） | 任务给出明确失败阶段与原因；已成功的角色/场景资产不丢失、可复用 |
| OK-004 | 一键成片任务列表 | P2 | 功能 | GET `/onekey/tasks` | 历史任务列表完整，含状态与时间 |
| OK-005 | 长剧本（多分镜）稳定性 | P1 | 性能 | 提交 10+ 分镜的剧本 | 任务不超时不丢分镜；总耗时随分镜数近似线性；产出完整视频集+配音 |
| OK-006 | 空剧本/超短剧本 | P2 | 边界 | 提交空文本、一句话剧本 | 空文本被拒；超短剧本给出至少 1 个分镜的合理产出或明确提示 |

## 模块 C：时间线合片与导出

|---|---|---|---|---|---|
| TL-001 | 分镜合片为 MP4 | P0 | 功能 | 1. GET `/timeline/engine` 确认引擎可用 2. POST `/timeline/merge` 提交 3 个分镜+配音 3. 轮询 `GET /timeline/tasks/{task_id}` | 终态成功；输出 MP4 可播放，分镜顺序正确、转场无黑帧 |
| TL-002 | 合片音画同步 | P0 | 质量 | 播放 TL-001 成片，检查台词与画面口型/节拍 | 音画偏差 ≤ 200ms，无音轨漂移 |
| TL-003 | 字幕与画面匹配 | P1 | 质量 | 带字幕配置合片 | 字幕时间轴与配音对齐，无叠字/错位 |
| TL-004 | 降级路径：剪映草稿 | P1 | 功能 | POST `/timeline/draft` | 生成剪映草稿目录，可在剪映中打开且轨道完整 |
| TL-005 | 项目级剪映导出 | P0 | 功能 | POST `/projects/export-jianyin`（带 project_id） | 导出草稿成功；`GET /projects/export-jianyin/engine` 引擎自检通过 |
| TL-006 | 项目导出与再导入闭环 | P1 | 功能 | GET `/projects/{pid}/export` 导出 → POST `/projects/import` 导入为新项目 | 新项目内容/画布/资产引用完整，可继续生成 |

## 模块 E：Agent / MCP 驱动生成（自然语言使用体验）

| 用例编号 | 标题 | 优先级 | 类型 | 步骤 | 预期结果 |
|---|---|---|---|---|---|
| AGT-001 | 对话式生成视频 | P0 | 体验 | POST `/agent/chat`："帮我生成一段 5 秒的猫在雪地里奔跑的视频" | Agent 调用 `generate_video` 工具，返回任务并附进度；无需用户手动填参数 |
| AGT-002 | SSE 流式响应 | P0 | 体验 | POST `/agent/chat/stream` | 事件按流式返回（工具调用过程可见），最终给出视频结果；连接不中断 |
| AGT-003 | MCP `generate_video` 工具 | P1 | 功能 | POST `/mcp/call`，tool=`generate_video`，含 previz 视频 | 任务创建成功；`previz_video_url` 被自动提升为参考视频 |
| AGT-004 | 剧本拆解接口 | P1 | 功能 | POST `/projects/parse-script`，输入小说片段 | 返回结构化项目（角色/场景/分镜），字段完整可渲染 |

| AGT-006 | 敏感/违规 prompt 拦截 | P0 | 安全 | 通过 chat 与 `/videos/generate` 分别提交违规内容 | 请求被拒绝或上游拦截信息清晰返回，无违规成片产出 |
